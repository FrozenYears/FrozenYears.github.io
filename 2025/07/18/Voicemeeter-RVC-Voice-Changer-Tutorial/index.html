Voicemeeter & RVC 实时变声器折腾指南

Created2025-07-18|Updated2026-09-06|Tutorial
|Word Count:1.2k|Reading Time:4mins|Post Views:
Abstract: 一篇关于花儿不哭开发的 RVC 实时变声器和虚拟音频混音软件 Voicemeeter 的使用与调试经验帖。

本文起源于与朋友开黑闲来无事时的鬼脑发动小巧思，实际证明效果还是很不错的（）

一、Voicemeeter 设置

（此处略去安装Voicemeeter软件部分，推荐安装Banana版本，声道更多，且免费，链接在文末）

1. 系统声音设置

Windows 声音设置改成这样：

设置项 选什么
默认输出设备 Voicemeeter Input
默认通信输出 Voicemeeter Input
默认输入设备 Voicemeeter Out B1
默认通信输入 Voicemeeter Out B1

Tip: 如果不设置默认通信设备，QQ、微信类的语音输入则不会经过 Voicemeeter 以及 RVC 的处理

Note： 设置完之后，系统音频（软件声音什么的）会走到 Voicemeeter Input。输入那边暂时检测不到声音——因为 Voicemeeter Out B1 是 Voicemeeter 的虚拟通道，而非物理声卡，正常的。

2. Voicemeeter 配置

界面一览

  • A = 硬件输出（监听用）
  • B = 虚拟输出（输出到应用程序）

区域划分

区域 干嘛的
左边 物理设备的音频输入（比如麦克风）
中间 系统和软件的音频输入
右边 主输出控制——A 走硬件监听，B 走软件输出

路由怎么走

  1. 想自己听到声音（监听）：

    • 在对应输入通道勾上 A1
    • 音频就会走到 A1，从耳机出来给你听（记得在右上角选择监听的设备）

  2. 想让应用收到声音：

    • 在对应输入通道勾上 B1
    • 软件就能通过默认输入设备（Voicemeeter Out B1） 收到处理后的音频

物理输入和输出设备建议设成 MME 格式。

用别的格式会影响变声质量，延迟也会变大。

二、RVC 变声器

1. 配置要求

最低配置：

  • GPU：NVIDIA GTX 1060 6GB 或 AMD RX580 8GB
  • CPU：Intel Core 或 AMD Ryzen（四核以上）
  • 内存：8GB 以上
  • 系统：Windows 10 或 Windows 11

推荐配置：

  • GPU：RTX 3060 8GB
  • CPU：Intel 12 代 i5 或 Ryzen 7000 系列以上
  • 内存：32GB 以上
  • 系统：Windows 10 或 Windows 11

提醒： AMD 和 Intel 显卡目前延迟偏高。想要最佳体验建议上 NVIDIA RTX 20 系列或更高。

2. 启动

下载 RVC 之后，目录长这样：

下载链接在文末，如若失效，请B站搜索花儿不哭

双击 go-realtime-gui.bat 启动实时变声器。

3. 基本设置

跟着来：

  1. 选 .pth 模型文件和对应的 .index 索引文件（可选）
  2. 设备类型选 MME
  3. 输入设备：选你的物理麦克风
  4. 输出设备：选 Voicemeeter AUX Input（跟系统音频分开走，便于单独控制音频输出）
  5. 打开 “使用设备采样率”

4. 参数调教指南

基础参数

参数 干嘛的 建议值
响应阈值 过滤低于阈值的声音 可以自己调着试试，太高会吞字
音调 调声音高低 男→女：12，女→男：-12，同性：~0，与个人声线有关
性别因子 声音粗细 正数变细，负数变粗
索引率 增强模型相似度 没匹配的 index 文件就填 0；有的话往上调
响度因子 输出音量 越高越响

音高检测算法

可选算法：

  • pm：延迟最低，CPU 占用最低。唱歌还行，吵闹环境说话就拉了
  • harvest：质量最好，CPU 吃得多。可以加进程数来降延迟
  • crepe：跟 harvest 差不多，但吃 GPU。基本被 rmvpe 取代了
  • rmvpe ⭐：开箱即用效果拉满，比 harvest/crepe 快，GPU 占用极少，强烈推荐

进阶设置

  • 采样长度： 决定延迟。越低延迟越小，但可能卡顿（特别开玩游戏，系统资源烧少的时候，容易触发机关枪（））
  • 淡入淡出长度： 理论上来说值越大越自然，但会增加延迟，可以自行测试权衡
  • 额外推理时间： 建议 1-3 秒。越高识字越准，但 CUDA 占用也容易升高

CPU 进程数（仅 Harvest 算法）：

  • 影响音质，不建议超过 4
  • 决定音高算法最多用几个 CPU 线程
  • 低了打游戏不卡但推理延迟上去
  • 高了推理快但游戏可能掉帧
  • 延迟够用的话就尽量往低了设
