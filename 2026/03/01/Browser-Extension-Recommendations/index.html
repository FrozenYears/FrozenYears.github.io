浏览器扩展推荐

Created2026-03-01|Updated2026-09-04|Resources
|Word Count:556|Reading Time:1mins|Post Views:
Abstract: 一份精选浏览器扩展清单——翻译、媒体提取、脚本管理、效率工具，好用的全在这了。

1. 翻译 & 语言学习

扩展 一句话介绍
沉浸式翻译 全页双语翻译，保留原始排版。翻译插件里的神。
TapWord 划词翻译 点一下或划一下就出翻译，行内字幕式显示。

2. 媒体提取

扩展 一句话介绍
cat-catch（猫抓） 嗅探网页里的媒体资源——m3u8 流、视频、音频，一网打尽。
IDM Integration Module 拦截下载请求丢给 IDM 多线程下载。（需要装 IDM）
bilibili Downloader 下载 B 站视频和音轨。

3. 脚本管理器

扩展 一句话介绍
Tampermonkey（篡改猴） 用户脚本管理器。往指定网页注入自定义 JavaScript。
ScriptCat（脚本猫） 加强版脚本管理器，支持后台自动化和定时任务。

4. 浏览器工具

扩展 一句话介绍
Dark Reader 给任何网站强制上暗色模式，护眼党必备。
SingleFile 把整个网页（HTML + 图片 + CSS）保存成一个离线文件。
Global Speed 全站视频/音频倍速控制，最高 16x。听网课利器
AdBlock 广告拦截。用过滤规则隐藏 DOM 元素、拦截网络请求。
LazyCat 书签清理 批量检测清理失效（404）书签。
Lime 起始页 替换默认新标签页，极简可定制，内存占用低。

5. Gemini Voyager

给 Gemini 网页版加 buff：

功能 干嘛用的
时间线 快速跳到对话历史里的任意位置
文件夹 给对话分类整理
Prompt 库 保存常用 prompt，一键调用
引用回复 选中文字直接在上下文里回复
宽度调节 自定义聊天宽度，代码块不再换行
导出 对话导出成多种格式
去水印 去掉 AI 生成图片的水印
公式复制 一键复制公式为 LaTeX 或 MathML（Word）
Mermaid 图表 把 Mermaid 代码渲染成流程图、时序图、甘特图
标签页标题同步 自动把对话标题同步到浏览器标签页
对话分支（Beta） 从历史任意节点分叉，试试不同方向
批量删除 多选批量删对话历史
