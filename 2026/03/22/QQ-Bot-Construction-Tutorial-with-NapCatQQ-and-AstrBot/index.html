用 NapCatQQ + AstrBot 搭一个 QQ 聊天机器人

Created2026-03-22|Updated2026-09-07|Tutorial
|Word Count:5k|Reading Time:20mins|Post Views:
Abstract: 从零搭建一个接了大模型的 QQ 机器人——NapCatQQ 做协议桥接，AstrBot 做 LLM 编排，包括人设配置、踩坑排障和插件开发。

UPDATE: 经过较长一段时间的实践，发现NapCatQQ作为协议桥，bot经常容易掉线，需要频繁再次登录。
遂寻得LLBot，直接取代NapCatQQ即可，后续配置流程大差不差。

其余令牌获取、LLBot配置等，阅读LLBot官方文档即可

1. 我们要搞什么

1.1 目标

搭一套智能 QQ 机器人系统，三件套：

  • AI 聊天 —— 接 LLM 大模型，私聊群聊都能聊，带上下文记忆、角色人设
  • 自定义命令 —— 斜杠命令和关键词触发，比如 /weather、/search、/help
  • 插件扩展 —— 定时任务、自动化流程，接第三方API，不烧 LLM token（比如每日新闻推送、股票提醒、游戏通知）

核心思路：AI 管自然语言，插件管结构化任务——功能拉满的同时 API 费用压到最低。

1.2 架构

组件 干嘛的
NapCatQQ 协议桥 —— 通过 OneBot V11 协议跟 QQ 客户端通信
AstrBot LLM 编排器 —— 处理消息、管理上下文、调 LLM API
LLM Provider AI 大脑 —— 生成智能回复（OpenAI、DeepSeek、Gemini、本地模型都行）
Reverse WebSocket 通信通道 —— 把 NapCatQQ 和 AstrBot 双向连起来

为啥搞这么复杂？ QQ 官方的机器人 zAPI 限制多、功能少，主动消息功能不全等等。NapCatQQ 是社区维护的 OneBot V11 实现，能解锁完整的机器人能力。AstrBot 把平台差异抹平了，提供统一的 LLM 接入层。

2. 准备工作

开搞之前，确认一下：

需要什么 版本 备注
Python ≥ 3.9 推荐 3.12+
Node.js ≥ 18.0 NapCatQQ 要用
QQ 号 随意 拿个小号当机器人
LLM API Key 随意 OpenAI、DeepSeek 或兼容的中转都行

账号安全提醒： 用专门的 QQ 小号跑机器人。QQ 可能会封禁自动化行为的账号。别拿大号上。

3. NapCatQQ 搭建

3.1 NapCatQQ 是什么

NapCatQQ 是基于 NTQQ（QQ 最新桌面架构）的协议端框架，实现了 OneBot V11 标准，提供干净的 WebSocket/HTTP API 给机器人框架用。

特点一览：

  • 完整 OneBot V11 实现
  • 内存占用低 —— 7×24 跑在最低配置上没问题
  • 活跃维护 —— 459+ releases，GitHub 8k Stars
  • 支持 Docker —— 一条命令部署
  • WebUI 管理 —— 浏览器里就能配

4. AstrBot 搭建

4.1 AstrBot 是什么

AstrBot 是一个 Python 写的多平台聊天机器人框架，原生集成了 LLM。支持 QQ、Telegram、Discord、企业微信等等。

核心能力：

  • 多平台 —— 一套代码，多个消息平台
  • 插件系统 —— 可扩展架构，想加啥功能AI自己写
  • WebUI 仪表盘 —— 浏览器里配置和监控
  • 上下文管理 —— 内置对话历史和压缩
  • 人设系统 —— 通过 System Prompt 自定义机器人性格

7. 人设配置

7.1 为啥人设很重要

人设（System Prompt）定义了机器人的性格、知识边界和回复风格。写好了能：

  • 搞出沉浸式角色扮演体验
  • 防止生成不当内容
  • 保持跨对话的角色一致性

7.2 配置人设

  1. 打开 AstrBot 仪表盘 → 人设 页面
  2. 写 System Prompt：
  1. Temperature 设 0.8 - 0.95，回复更有创意
  2. 点 保存

7.3 人设写作技巧

Dos：

  • 用正面表述代替否定禁令
  • 定义回复格式（动作描写、语气、长度）
  • 设定知识边界（角色知道什么不知道什么）
  • 加示例对话（Few-Shot），保持一致性

Don’ts：

  • 别用 “violence”、”explicit”、”nsfw” 这些词——就算是在禁止也别用
  • System Prompt 别写太长（>2000 tokens）
  • 别写自相矛盾的指令
  • 别忘了拿边界输入测试

WAF 过滤预警： 有些 LLM 提供商用 WAF（Web 应用防火墙） 拦截含敏感关键词的请求——哪怕是写在 System Prompt 里的。

反面教材： “Never generate violent or sexual content”
正确姿势： “Maintain wholesome, family-friendly conversations. Politely decline inappropriate requests with a gentle rebuke.”

8. 踩坑排障

8.1 常见问题

问题一：扫码登录失败，多进程报错

症状： 反复扫码都失败，控制台报：

原因： NapCat 的多进程模式跟环境冲突了，worker 进程登录时直接崩。

解法： 加环境变量关掉多进程模式：

  1. 打开 NapCat 的 .bat 启动文件
  2. 在 @echo off 后面加 set NAPCAT_DISABLE_MULTI_PROCESS=1
  3. 保存，重启 NapCat

问题二：403 Forbidden — Text Not Allowed

原因： LLM 提供商的 WAF 拦了你的请求。

解法：

  1. 关掉 AstrBot 自带的”安全模式” —— 它默认的 prompt 里有敏感词
  2. 审查你的人设 —— 把敏感关键词删掉
  3. 换个提供商 —— 有些代理的 WAF 比别的严

问题三：发图片触发 403

原因： 纯文本模型（比如 DeepSeek-V3）处理不了图片。AstrBot 把图片转成 Base64，一大长串文本触发了 WAF 的”可疑长文本”检测。

解法：

  1. 关掉 AstrBot 的图片理解功能
  2. 图片单独走 —— 只用支持视觉的模型（GPT-4o-mini、Gemini Flash）处理图片

问题四：改完配置等了 30 多秒才恢复

原因： AstrBot 热重载配置时会重置 WebSocket 连接。NapCat 的重连延迟造成了空窗期。

解法：

  1. 等它重连 —— 盯着控制台看 adapter connected 消息
  2. 把 NapCat 重连间隔调到 3000ms
  3. 都没用就两边都重启

问题五：群里不回消息

原因：

  • 群聊需要 @机器人 才触发
  • 机器人的 QQ 号登录过期了

解法：

  1. 检查 AstrBot 仪表盘的群组设置，或者设置触发条件
  2. 重启 NapCatQQ 重新登录

8.2 排障清单

看终端输出拿报错信息

检查项 怎么查
AstrBot 跑着没？ python main.py 或查进程

LLM API 通不通？ 在 AstrBot WebUI 里试聊
日志干净吗？ 看 AstrBot 和 NapCat 控制台输出
