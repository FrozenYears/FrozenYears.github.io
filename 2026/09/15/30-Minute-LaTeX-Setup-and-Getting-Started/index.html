30分钟 LaTeX 配置与入门

Created2026-09-15|Updated2026-09-19|Tutorial
|Word Count:4.9k|Reading Time:20mins|Post Views:
Abstract: LaTeX 环境配置与入门语法速查——TeX Live 安装避坑、VS Code + LaTeX Workshop 编译配置，以及文档骨架、数学公式与交叉引用的基础写法。

虽然但是，我是因课程要求被迫从 Typst 转 LaTeX ，相比而言，Typst 真的轻好多

  • LaTeX 是一种基于 TeX 的排版系统，广泛用于生成高质量的科技和数学文档。

  • LaTeX 在 TeX 的基础上提供了更高层次的抽象，使得用户可以更专注于内容，而无需过多担心排版细节。

  • 与常见的文字处理软件（如 Microsoft Word）不同，LaTeX 使用纯文本文件来描述文档的结构和内容，并通过编译生成最终的 PDF 文件。

  • LaTeX 特别适合处理复杂的数学公式、参考文献、交叉引用等。

  • 随着时间的推移，LaTeX 逐渐成为学术界和出版界的标准工具之一。

1. 环境配置

本文主要以Windows环境下配置为例

1.1 TeX、LaTeX、宏包与发行版的关系

整个 TeX 生态可以分成四层，自下而上分别是：引擎、格式、宏包、编辑器。

  • 引擎是真正把源码排成 PDF 的程序，常见的有 TeX、pdfTeX、XeTeX、LuaTeX。其中 XeTeX 和 LuaTeX 原生支持 Unicode 和系统字体，这也是中文文档推荐用它们编译的原因
  • 格式是构建在引擎之上的一套命令规则，LaTeX 就是目前最流行的格式
  • 宏包则是在格式之上继续扩展功能的插件，比如中文支持（ctex）、数学公式增强（amsmath）、页面设置（geometry）。CTAN 上收录的宏包有五千多个
  • 最后，把引擎、格式和海量宏包打包在一起、方便一次性安装的集合，就叫发行版（Distribution），例如 TeX Live、MiKTeX

1.2 LaTeX 的基本工作流程

LaTeX 的工作流程可以概括为三步：写源码、运行编译、得到 PDF。

1.3 LaTeX 的安装

1.3.1 Windows 系统

在 Windows 系统上，推荐使用 TeX Live 或 MiKTeX 来安装 LaTeX。

1.3.1.1 安装 TeX Live（推荐，稍后会详细介绍）

  • 下载 TeX Live：访问 TeX Live 官方网站，下载适合你系统的安装程序。
  • 运行安装程序：双击下载的安装程序，按照提示进行安装。TeX Live 的安装过程较为耗时，因为它包含了大量的宏包和工具。
  • 配置环境变量：安装完成后，确保 TeX Live 的 bin 目录已添加到系统的 PATH 环境变量中。

1.3.1.2 安装 MiKTeX

  • 下载 MiKTeX：访问 MiKTeX 官方网站，下载适合你系统的安装程序。
  • 运行安装程序：双击下载的安装程序，按照提示进行安装。建议选择"完整安装"以确保所有常用宏包都已安装。
  • 配置环境变量：安装完成后，确保 MiKTeX 的 bin 目录已添加到系统的 PATH 环境变量中。这样可以在命令行中直接使用 LaTeX 命令。

1.3.2 macOS 系统

在 macOS 系统上，推荐使用 MacTeX 来安装 LaTeX。

1.3.2.1 安装 MacTeX

  • 下载 MacTeX：访问 MacTeX 官方网站，下载适合你系统的安装程序。
  • 运行安装程序：双击下载的 .pkg 文件，按照提示进行安装。MacTeX 包含了 TeX Live 和相关的 GUI 工具。
  • 配置环境变量：安装完成后，确保 TeX Live 的 bin 目录已添加到系统的 PATH 环境变量中。

1.3.4 Windows 系统上 Tex Live 的下载与安装避坑

这里有两种安装途径：

  • 一种是下载ISO镜像，本地挂载安装（推荐，耗时更短）
  • 另一种是通过官方下载器安装
    理论上，安装速度一般应该遵循：本地 ISO 镜像 > 在线网络安装（国内镜像源） > 在线网络安装（默认官方源）

1.3.4.1 使用ISO镜像安装 Tex Live（推荐）

  1. 访问清华大学开源软件镜像站下载镜像texlive.iso到本地
  1. 双击texlive.iso以挂载镜像
  1. 以管理员身份运行install-tl-windows.bat

以管理员身份运行，即选择“为所有人安装”该应用程序，适合于安装底层编译链、全局运行库时使用，以避免未来使用过程中带来不便

  1. 点开安装程序的“Advanced”选项卡
  1. 取消勾选“Install font/macro doc tree”和“Install font/macro source tree”

这样做的好处是直接剔除一大堆又臭又长的说明文档和源代码（剔除不影响使用），将安装体积从10个G左右缩减至5个G左右。此外，剔除用不到的小语种还能进一步缩减安装体积。

但不建议安装精简版 LaTeX（削减宏包或字体之类），否则在进行大型学术排版时，使用到系统里没有的宏包会报错。

  1. (漫长的等待) 这个时候你应该往下翻到 VS Code 配置，或 LaTeX 基础语法
  1. 最后，可以在终端里再验证一下。Win + R打开cmd，输入以下命令，正确输出版本信息即可

编辑器决定你「写」的体验，它可以随时更换，与发行版互相独立。

2. LaTeX 基础语法

LaTeX 的底层逻辑是“所想即所得”的标记语言：通过源文件中的命令控制排版逻辑，最终交由编译器生成 PDF。

2.1 基础骨架与核心规则

任何 .tex 文档都由导言区和正文环境两部分构成：

  • 命令格式：以反斜杠 \ 开头，可选参数放中括号 [...]，必选参数放花括号 {...}，例如 \documentclass[11pt]{article}。
  • 环境格式：成对出现的 \begin{环境名} ... \end{环境名}，正文本身就是一个名为 document 的大环境。
  • 换行规则：源码中的单次回车在输出中视为空格；连续敲两次回车（留一个空行）才代表真正分段。强制换行使用 \\。

2.4 数学公式排版

LaTeX 最核心的优势在于数学公式表达。数学模式必须在专属边界内声明：

  • 行内公式：使用一对单个 $ 包裹，例如 $E = mc^2$，公式高度自动匹配文本行高。
  • 独立行间公式：使用 \[ ... \] 包裹（或使用旧语法 $$ ... $$），公式独立成行且自动居中：

2.4.1 高频数学元素语法

  • 上下标：下标为 _，上标为 ^。如果上/下标包含多于一个字符，必须用花括号包裹。例如 x_i^2、a_{n+1}、e^{-\lambda t}。

  • 分式与根号：\frac{分子}{分母}，\sqrt{x}，开 nnn 次方使用可选参数 \sqrt[n]{x}。

  • 希腊字母：\alpha, \beta, \lambda, \sigma；首字母大写即对应大写字母，如 \Delta, \Omega。

  • 自适应括号：普通括号包不住高大的分式或积分时，使用 \left( 与 \right)，系统会根据内部高度自动拉伸括号：

    使用 & 标记垂直对齐锚点，使用 \\ 标记换行，带 * 号的环境默认不生成公式编号。

2.5 交叉引用机制

科技文档排版严禁手动硬编码“见第 3 节”或“见公式 5”。LaTeX 采用全局引用体系：

  1. 埋点：在需要引用的目标位置打上标签 \label{key}（必须紧跟在 \caption{}、\section{} 或公式环境内）。
  2. 引用：在正文中通过 \ref{key} 引用图表或章节号，通过 \eqref{key} 引用公式编号（自带圆括号）。

提示：交叉引用在初次编译时会将标签暂存至中间辅助文件（.aux），通常需要运行两次编译，引用的序号问号（??）才会正确解析为数字。
