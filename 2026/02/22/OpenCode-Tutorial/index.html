OpenCode 使用教程

Created2026-02-22|Updated2026-09-04|Tutorial
|Word Count:2.3k|Reading Time:9mins|Post Views:
Abstract: OpenCode CLI 完整指南——安装、通过 Ollama 接入本地大模型、以及用 Oh-My-OpenCode 插件解锁多 Agent 协作。

1. 概览

1.1 OpenCode 是什么？

OpenCode 是一个开源的 AI 编程 Agent，拥有操作系统级别的权限。跟网页版 LLM 不一样，它能：

  • 读写、创建文件
  • 执行终端命令
  • 搜索和分析整个代码库
  • 自动修 bug（闭环开发）

1.2 核心特性

特性 说明
开源 GitHub 100k+ Stars，免费
多模型 支持 75+ 供应商
隐私优先 支持本地模型
终端 UI 资源占用极低
内置 Agent Build Mode + Plan Mode

2. 为什么选 CLI 而不是网页聊天

2.1 核心区别

维度 OpenCode CLI 网页 LLM
角色 干活的 出主意的
交互方式 直接读写文件 手动复制粘贴
上下文 感知整个仓库 只有单次会话
闭环 自动修复 手动反馈
隐私 完全本地 云端 API

2.2 关键变化

  1. 上下文管理：自动扫描 Git 仓库，构建 AST / Repository Map
  2. I/O 革命：直接生成 Git Diff，告别复制粘贴
  3. Agentic Loop：写代码 → 跑 → 报错 → 自动修 → 搞定

想问/学东西？去用免费的网页 LLM 聊。

想做/建东西？上 CLI Coding Agent，效率拉满。

更新：
深入研究后发现，本地模型（PC 端）在上下文快速增长时表现很拉。输入的上下文稍微大一点，推理时间直接翻倍。
一句话总结：除非是为了隐私，别在 OpenCode + Oh-My-OpenCode 里用本地模型。

Step 0: 配置环境变量

（如果你不想让大模型装到 C 盘的话）

  • 打开环境变量设置
  • 新建一个系统变量
  • 变量名填 OLLAMA_MODELS
  • 变量值填你想放模型的目录，比如 D:\OllamaModels

6. Oh My OpenCode 插件

不装 Oh My OpenCode，OpenCode 只发挥了 30% 的功力。

6.1 Oh My OpenCode 是什么？

一个插件，把单 Agent 升级成多 Agent 协作团队。

GitHub: code-yeongyu/oh-my-opencode

6.2 核心 Agent

Agent 职责
Sisyphus (Ultraworker) 总指挥，分配任务给专业 Agent，并行推进直到 100% 完成
Hephaestus (Deep Agent) 深度研究，硬核逻辑任务，深入分析
Prometheus (Plan Builder) 代码库导航、探索、发现模式
Atlas (Plan Executor) 执行预定义的多步骤计划

在 %USERPROFILE%\.config\opencode\oh-my-opencode.json 里自定义 Agent 和分类。

Agent 职责 推荐模型
Sisyphus 总指挥，任务分配 综合能力最强、上下文窗口最大的通用模型
Hephaestus 深度执行，复杂 bug 修复 代码生成和逻辑能力极强的模型；推荐免费无限量模型防止 rate limit
Oracle 架构设计，调试 顶级推理模型，强 Chain-of-Thinking (CoT)
Librarian 文档，代码调研 超长上下文理解、极低成本的模型
Explore 快速代码搜索 低延迟模型；推荐本地小参数高频模型，零成本快速并发
Multimodal-Looker 视觉分析（截图、PDF） 原生多模态模型，强 Vision 能力
Prometheus 任务规划 逻辑推理能力强的模型
Metis 方案咨询 逻辑推理和批判性分析强的模型
Momus 代码审查 指令遵循和批判性思维强的模型
Atlas 方案执行 指令遵循强、响应快的模型
分类 适用场景 推荐模型
visual-engineering 前端、UI 实现 Vision 能力强、前端专精的模型
ultrabrain 硬核逻辑、算法重写 顶级推理模型，极致算力
deep 深度代码实现 逻辑推理能力强的模型
artistry 创意代码设计 创造力 + 推理兼具的模型
quick 小修小补 小参数快速模型
unspecified-low 简单任务 小参数快速模型
unspecified-high 复杂未分类任务 高推理能力模型
writing 文档、注释 通用模型

6.8 斜杠命令与 Skills

Oh My OpenCode 在 OpenCode 内置命令基础上又加了一批：

命令 说明
/init-deep 在项目树中生成分层的 AGENTS.md
/start-work 通过 Atlas 执行 Prometheus 生成的计划
/ralph-loop 自引用循环——Agent 持续干活直到任务完成
/ulw-loop 同上，但开启 ultrawork 模式
/refactor LSP + AST-grep 驱动的重构，TDD 验证
/cancel-ralph 停止活跃的 Ralph Loop
/handoff 创建上下文摘要，方便在新会话中继续
/stop-continuation 停止所有续接机制

内置 Skills（通过 agent prompt 里的 load_skills=[...] 加载）：

Skill 触发场景 说明
playwright 浏览器任务、截图 通过 Playwright MCP 驱动浏览器自动化
frontend-ui-ux UI/UX、样式 设计师人格——大胆美学、个性化排版
git-master commit、rebase、squash 原子提交、历史重写、blame/bisect
dev-browser 导航、填表、抓取 持久化浏览器状态自动化
